## Project Overview

ALORA was created in 2026 as an individual web development project.  
ALORA is a clothing brand focused on comfortable and stylish clothing.

## Website Goals and Objectives

The goals and objectives of the ALORA website are:

- To promote the ALORA clothing brand.
- To showcase the clothing collection.
- To provide customers with product information.
- To allow customers to view available colour choices.
- To provide an easy way for customers to make enquiries.
- To create a simple and user-friendly website.

## Key Features and Functionality

The website includes the following features:

- Product catalogue
- Product images
- Colour choices
- Navigation menu
- Enquiry form
- Contact page
- About Us page
- Homepage

Users can view products, navigate between pages, view product information, select colour choices and make enquiries.
